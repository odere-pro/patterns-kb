# site/assets — presentation and derived data

Two kinds of file live here, and the split is the rule.

## Generated — never edit

| file | emitted by |
|---|---|
| `graph.json` · `catalog.json` · `catalog.js` · `graphdata.js` | `scripts/build.mjs` |

Regenerate with `make all`; `make check` fails when any is stale.

## Hand-authored

Everything else — `theme.js`, `lens.js`, `search.js`, `favourites.js`, `progress.js`,
`sketch.js`, `diagram.js`, `graph-view.js`, the CSS, the vendored libraries. Edits here
cannot break KB validity, so the post-edit hook only syntax-checks `.js` files
(`node --check`). Vendored libraries (`vendor/`) are third-party — update by replacing
the file and its LICENSE, never by editing.

## The interactive graph (`map/graph.html`) is three layers

| layer | file | owner |
|---|---|---|
| shell (header, tabs, legend, controls, empty SVG, noscript) | `map/graph.html` | generated by `scripts/build-graph-page.mjs` |
| data (`window.KB_GRAPH`: nodes, typed relations, presets) | `graphdata.js` | generated by `scripts/build.mjs` |
| runtime (force layout, Explore/Build modes, panel) | `graph-view.js` + `graph.css` | hand-authored |

Contracts the layers share — break one and the page silently degrades:

- **Family canonicalization** — a directional verb pair collapses onto its sorted-first
  verb. `build-graph-page.mjs` (legend buttons), `graph-view.js` (edge classes) and
  `graph.css` (`fam-*` colors) all use the same rule and must stay in agreement.
- **`window.KB_MATCHES`** — `search.js` exposes the hub's lexical scorer for the graph's
  symptom search. That export is the only coupling between the two files.
- **Classes only** — `graph-view.js` never sets a color or style inline; every color
  lives in `graph.css` keyed off theme tokens, so the theme switch recolors the canvas
  with no JS.
- **Data ships as a script, not a fetch** — `fetch()` is blocked on `file://`, and the
  site must work from `file://`.
- **URL hash is the state** — mode, seed and applied patterns serialize into
  `location.hash`, so a build is a shareable link and reload restores it.
- **`BUILDER_PRESETS`** live in `scripts/lib/model.mjs`; a candidate id with no page
  fails the build (`build.mjs`) and `make test`.

Changing graph behavior? Use the **kb-graph** skill — it carries the full contract and
the manual verification checklist.
